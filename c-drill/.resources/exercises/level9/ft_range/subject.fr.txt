Nom du programme : ft_range
Fichiers rendus  : ft_range.c
Fonctions autorisees : malloc
--------------------------------------------------------------------------------

Ecrire la fonction suivante :

int	*ft_range(int start, int end);

Elle doit allouer (avec malloc()) un tableau d'entiers, le remplir avec les
valeurs consecutives allant de start a end (start et end inclus !), puis renvoyer
un pointeur sur la premiere valeur du tableau.

Exemples :
- Avec (1, 3) vous renvoyez un tableau contenant 1, 2 et 3.
- Avec (-1, 2) vous renvoyez un tableau contenant -1, 0, 1 et 2.
- Avec (0, 0) vous renvoyez un tableau contenant 0.
- Avec (0, -3) vous renvoyez un tableau contenant 0, -1, -2 et -3.
