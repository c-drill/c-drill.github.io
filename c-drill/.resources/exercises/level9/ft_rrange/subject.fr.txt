Nom du programme : ft_rrange
Fichiers rendus  : ft_rrange.c
Fonctions autorisees : malloc
--------------------------------------------------------------------------------

Ecrire la fonction suivante :

int	*ft_rrange(int start, int end);

Elle doit allouer (avec malloc()) un tableau d'entiers, le remplir avec les
valeurs consecutives allant de end a start (start et end inclus !), puis renvoyer
un pointeur sur la premiere valeur du tableau.

Exemples :
- Avec (1, 3) vous renvoyez un tableau contenant 3, 2 et 1.
- Avec (-1, 2) vous renvoyez un tableau contenant 2, 1, 0 et -1.
- Avec (0, 0) vous renvoyez un tableau contenant 0.
- Avec (0, -3) vous renvoyez un tableau contenant -3, -2, -1 et 0.
