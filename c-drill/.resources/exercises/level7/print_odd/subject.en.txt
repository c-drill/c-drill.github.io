Assignment name  : print_odd
Expected files   : print_odd.c
Allowed functions: write
--------------------------------------------------------------------------------

Write a program that takes numbers as arguments and displays, for each of them,
the number if it is odd, followed by a newline.
Arguments are integers (they may be negative).
If a number is even it is skipped. If there are no arguments, or if none of the
numbers is odd, the program displays nothing.

Examples:
$> ./print_odd 5 | cat -e
5$
$> ./print_odd 1 2 3 4 5 | cat -e
1$
3$
5$
$> ./print_odd 10 -7 22 -3 | cat -e
-7$
-3$
$> ./print_odd 2 4 6 | cat -e
$> ./print_odd | cat -e
$>

examples may differ slightly from the real exam.
