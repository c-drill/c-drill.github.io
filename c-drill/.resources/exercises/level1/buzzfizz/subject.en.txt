Assignment name  : buzzfizz
Expected files   : buzzfizz.c
Allowed functions: write
--------------------------------------------------------------------------------

Write a program that prints the numbers from 1 to 100, each separated by a
newline.
If the number is a multiple of 3, it prints 'buzz' instead.
If the number is a multiple of 5, it prints 'fizz' instead.
If the number is both a multiple of 3 and a multiple of 5, it prints 'buzzfizz'
instead.

Example:
$> ./buzzfizz
1
2
buzz
4
fizz
buzz
7
8
buzz
fizz
11
buzz
13
14
buzzfizz
[...]
97
98
buzz
fizz
$>
