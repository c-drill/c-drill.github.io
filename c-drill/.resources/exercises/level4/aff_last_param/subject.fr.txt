Nom du programme : aff_last_param
Fichiers rendus  : aff_last_param.c
Fonctions autorisees : write
--------------------------------------------------------------------------------

Ecrire un programme qui prend des chaines en argument et affiche son dernier
argument suivi d'un retour a la ligne.
Si le nombre d'arguments est inferieur a 1, le programme affiche un retour a la
ligne.

Exemples :
$> ./aff_last_param "zaz" "mange" "des" "chats" | cat -e
chats$
$> ./aff_last_param "j'aime le savon" | cat -e
j'aime le savon$
$> ./aff_last_param | cat -e
$
